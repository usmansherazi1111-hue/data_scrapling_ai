Auth profiles

    
A profile holds cookies (and optional headers / user-agent) that every fetch mode sends. Use it for sites that need a login, or for sites that show a CAPTCHA: open the site in a real browser window, log in or solve the challenge yourself, then click Finish & save. Select the profile under Access options when crawling. Cookies are stored in plain text in data/profiles.
